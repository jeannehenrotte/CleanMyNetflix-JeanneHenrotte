# CleanMyNetflix-JeanneHenrotte

https://github.com/jeannehenrotte/CleanMyNetflix-JeanneHenrotte.git

Single Page Application designed to explore movie catalogs, organize your viewing space, and manage your favorites in a smooth and interactive way.

## Main Features

* Smooth Navigation (Swiper.js):
  The application works like a modern carousel. You can switch between sections by swiping the screen with your mouse, using the arrow buttons, or clicking directly on the top navigation menu.

* Drag-and-Drop Favorites (Interact.js): 
  In the "Favorites" section, you can grab your favorite titles with your mouse and freely rearrange them across the screen.

* Design and Styling (SASS / SCSS):
  The visual style is inspired by Netflix's dark and clean aesthetic, featuring high-contrast colors and an organized layout built with modern, structured CSS.

* Smooth Animations (AnimeJS):
  Dynamic micro-animations welcome the user as soon as the page loads, making the interface feel more alive.
